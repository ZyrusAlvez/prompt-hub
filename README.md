# Prompt Hub

**Prompt Hub** is a project built for my **Project-Based Learning** journey, where I am learning Next.js and TypeScript. This project aims to provide a platform for users to share and copy prompts for various creative uses.

## Technologies Used

- **Next.js**: The main framework for building the application, utilizing React for the frontend.
- **TypeScript**: To ensure strong typing and better development practices.
- **Tailwind CSS**: For fast and responsive UI styling.
- **MongoDB**: To store prompt data, user information, and other necessary details.
- **Google Authentication**: Allowing users to sign in using their Google accounts.
- **Express.js**: Used to set up the backend for API routes and server-side logic.
- **Loading Skeletons**: For providing smooth and visually appealing loading states while data is being fetched.

## Features

- **Prompt Collection**: Users can share, copy, and explore various prompts for different creative tasks.
- **User Authentication**: Implementing **Google Auth** for easy sign-in and user management.
- **Responsive UI**: Styled with **Tailwind CSS** to ensure the app looks great on all screen sizes.
- **Loading Skeletons**: Display skeleton loaders for smooth transitions during data fetching.
